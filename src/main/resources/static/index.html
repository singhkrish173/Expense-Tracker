ExpenseTracker

A powerful, modern personal finance and cash flow management platform engineered with Spring Boot, MySQL, and responsive Glassmorphism UI.

100% Pure Tech Stack
24/7 MySQL Persistence
Dual Dark & Light Themes
Private User Data Isolation

Core Capabilities

Income & Expense Tracking

Easily log and classify day-to-day expenditures and multiple income streams with detailed categorization, date logging, and notes.

Monthly Budget & Analytics

Visualize your spending ratios, net balances, and dynamic category breakdown progress bars across any selected month of the year.

Smart Search & Filtering

Instant multi-criteria filtering by category, transaction type, custom date ranges, and live full-text search across all descriptions.

User Authentication & Storage

Create your private account to store, isolate, and access your financial records securely from anywhere via dedicated MySQL storage.

Technology Stack Architecture

Java 17 LTS
Spring Boot 3.2.4
Spring Data JPA & Hibernate
MySQL 8.4 Server
HTML5 Semantic UI
Vanilla Glassmorphic CSS3
Vanilla JavaScript (ES6+)

Financial Rule of Thumb: The 50 / 30 / 20 Rule

Allocate 50% of your income to Needs (rent, bills, groceries), 30% to Wants (entertainment, dining, shopping), and 20% to Savings and Investments. Use the Monthly Overview in ExpenseTracker to monitor your ratio in real time.
